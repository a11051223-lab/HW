# HW5
作業 5：向量相似度實驗                                                    
任務描述：
使⽤ Embeddings API，實驗不同⽂字之間的相似度計算。
步驟指引：
1.     參考課程的 Embeddings 程式碼（包含建⽴向量和計算相似度功能）
2.     建⽴相似度測試程式
3.     準備 3 組測試⽂字（每組 3 句）：
第 1 組：意思相近的句⼦（如：「我喜歡喝咖啡」「咖啡的⾹氣很迷⼈」「我每天早上都要喝⼀杯咖啡」）
第 2 組：意思不同的句⼦（如：「⾼鐵快要進站了」「這部電影很好看」「⼿機快沒電了」）
第 3 組：⾃⼰設計的測試案例
4.     計算每組句⼦之間的相似度
5.     分析結果，驗證相似度是否符合預期

繳交內容：
Embeddings 相關程式

相似度測試程式驗收標準：
能成功呼叫 Embeddings API 取得向量
能計算並輸出兩兩句⼦的相似度
README 附兩兩相似度數值，並以 1-2 句說明第 1 組與第 2 組的差異是否符合預期

-----------------------答案-----------------------------

@a11051223-lab ➜ /workspaces/HW (HW5-) $ node similarity-test.js

=== 第 1 組：意思相近（咖啡主題） ===
  句1：我喜歡喝咖啡
  句2：咖啡的香氣很迷人
  句3：我每天早上都要喝一杯咖啡
相似度結果：
  句1 vs 句2: 0.6792
  句1 vs 句3: 0.7346
  句2 vs 句3: 0.5473

=== 第 2 組：意思不同（隨機主題） ===
  句1：高鐵快要進站了
  句2：這部電影很好看
  句3：手機快沒電了
相似度結果：
  句1 vs 句2: 0.1828
  句1 vs 句3: 0.3820
  句2 vs 句3: 0.2286

=== 第 3 組：自設案例（星座主題） ===
  句1：天蠍座的人個性神秘深沉
  句2：天蠍座擅長洞察他人心思
  句3：今天天氣晴朗很適合出遊
相似度結果：
  句1 vs 句2: 0.7452
  句1 vs 句3: 0.2358
  句2 vs 句3: 0.2378


=== 分析結論 ===
第1組（意思相近）兩兩相似度應明顯高於第2組（意思不同）。
此結果驗證 text-embedding-3-small 能有效捕捉中文語意相似性。
